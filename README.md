## Featured Project/s

### Monster Game V1
A text-based RPG combat game built entirely from scratch to run right in the terminal.

* **The Core Features:**
  * A secure player login system backed by a custom Python dictionary.
  * Dynamic, randomized monster encounters where enemies scale.
  * A full turn-based combat system loop allowing users to choose actions.
  * A smart healing potion mechanic that uses logic to strictly clamp health so it never crosses the maximum limit.

* **Python Concepts Mastered Here:** * Game loops (`while True`) and structured exit sequences.
  * Complex conditional logic arrays (`if / elif / else`).
  * Utilizing data structures like lists and dictionaries to track user info.
  * Importing and using an external standard module (like `random`)


### All Type Calculator
A multi-use calculator, which can run right in the terminal with ease

* **The Core Features:**
* You can utilise basic math operators to add, subtract, divide and multiply
* Convert Miles to Kilometers
* Convert Celcius to Fahrenheit

* **Python Concepts Practised / Mastered:**
* Control flow loops - Allowing the program to run indefinitely and allowing the user to correct mistakes easily without restarting the script
* Functional Programming - Allowing users to identify and clearly input what is being asked. E,g: "Please enter the Celcius:"
* Nested Conditional Logic - Directs information correctly. E,g: 1 == Addition, 2 == Subtraction. If user picked 1, it wouldnt go to 2
* Identifying Str and Int - Learning the hard way, the difference between integers and str representation of numbers....
* Type Casting - Utilising float(), i am forcing python to convert text to decimal numbers used in the mathematics of the calculator.
